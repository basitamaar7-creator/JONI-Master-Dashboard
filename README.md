## 🚀 Quick Installation

### Step 1: Clone Repository
```bash
git clone https://github.com/basitamaar7-creator/JONI-Master-Dashboard.git
cd JONI-Master-Dashboard
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Setup Configuration
```bash
cp .env.example .env
# Edit .env with your API keys
```

### Step 4: Start Application
```bash
npm start
```

**Website opens**: `http://localhost:3000`

## 📱 Multi-Device Setup

### Phone 2 Installation (Auto Sync):
```bash
git clone https://github.com/basitamaar7-creator/JONI-Master-Dashboard.git
cd JONI-Master-Dashboard
```

## 🔄 Sync Across Devices

Jab aap phone 1 mein kuch change karo:
1. Local Storage update hota hai (instant)
2. Cloud mein save hota hai
3. Phone 2 mein automatically sync hota hai
4. Laptop mein bhi dikta hai

**Sab devices mein SAME data** ✅
