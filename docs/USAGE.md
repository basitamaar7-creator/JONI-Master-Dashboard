## 🔊 Voice Assistant

### کیسے استعمال کریں:

1. **Microphone آئیکن پر کلک کریں**
2. **اپنی بات کہیں**
3. **JONI سنے گا اور جواب دے گا**

### Commands:
```
"JONI, مجھے ایک joke سنا"
"JONI, میرا To-Do list دکھا"
"JONI, Facebook پر post کرو"
"JONI, current time بتا"
```

---

## 📝 To-Do List

### نیا Task Add کریں:
1. **"Add Task" پر کلک کریں**
2. **Task لکھیں** (مثال: "Grocery خریدنا")
3. **Category منتخب کریں** (Work, Personal, Shopping)
4. **Reminder set کریں** (Optional)
5. **Save کریں**

### Task Manage کریں:
- ✅ **Complete**: Task کو مکمل کریں
- 🗑️ **Delete**: حذف کریں
- ✏️ **Edit**: تبدیل کریں
- 📌 **Pin**: اہم کریں

### Voice Commands:
```
"JONI, Shopping میں نے دودھ ڈالو"
"JONI, میرے تمام tasks دکھا"
"JONI, Work کے tasks مسلسل کریں"
```

## 🕐 World Clock

### Timezones شامل کریں:
1. **"+ Add Timezone" پر کلک کریں**
2. **City/Country منتخب کریں**
   - London
   - New York
   - Dubai
   - Tokyo
   - etc.
3. **Add کریں**

### Features:
- 🌍 24+ Timezones
- ⏰ 12/24 Hour Format
- 🔄 Real-time Updates
- 📊 Time Difference Calculator

### Voice Commands:
```
"JONI, Dubai میں کتنا وقت ہے?"
"JONI, London اور اسلام آباد میں فرق بتا"
"JONI, UTC+5 میں time کیا ہے?"
```
